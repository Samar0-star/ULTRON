## 5. Adversarial Loop Optimization & Unbreakability Index

Once an experiment succeeds, it enters the **3-Tier Falsification Pipeline** (Lines 985–1057):

### Tier A: Deep Statistical Falsification (`run_falsification_gate`, Lines 988–1017)
1. Parses `GROUNDING_DATA:(.*)` emitted by the sandbox.
2. Passes raw control/treatment distributions into `FalsificationEngine`.
3. Runs 1,000 bootstrap shuffles, label-flipping, and semantic counter-hypothesis checks.
4. Computes **Standardized Rigor Index**:
   $$\text{Rigor Index} = (\text{survival\_rate} \times 0.6) + \text{semantic\_bonus (0.2)} + \text{significance\_bonus (0.2)}$$
5. If fatal attacks succeed, overrides `evidence_type = "refute"`.

### Tier B: Numerical Stress Search & Unbreakability Index (`_run_adversarial_pass`, Lines 1018–1027, 2130–2217)
1. Code is scanned for `FALSIFICATION_BOUNDS = {"param_a": (min, max), ...}`.
2. Defines an adversarial objective function:
   $$\min_{\vec{x}} - \text{objective}(\vec{x}) \iff \max_{\vec{x}} p(\vec{x})$$
   It uses `scipy.optimize.differential_evolution` to actively hunt for parameter vectors that drive the p-value towards 1.0 (noise).
3. **Unbreakability Index Calculation**:
   $$\text{Unbreakability Index} = 1.0 - \min(1.0, \text{worst\_case\_p\_value})$$
4. **Kill Threshold**: If `unbreakability_index < 0.3`, the hypothesis is declared **broken** by numeric optimization and downgraded to `"inconclusive"`.

### Tier C: Mandatory Adversarial Audit on Raw CSV (Lines 1028–1056)
Scans stdout for `CSV_DATA_START\n(.*?)\nCSV_DATA_END`. If present, feeds data into `AdversarialExecutor.attack_hypothesis(df, target, hypothesis)`. If the verdict is `COLLAPSED`, the experiment is flagged as refuted.
