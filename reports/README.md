# SVEL Epistemic Discovery Dossiers & Research Archive

This directory houses the formal scientific discovery dossiers, mission journals, forensic audit ledgers, and architectural deepdives generated by the **Scientific Verification Engine Layer (SVEL)**.

Every discovery dossier in this repository adheres to strict **Karl Popper dual-stream Epistemic Falsification** standards: eliminating narrative prose in favor of mathematical framing, boundary-condition stress tests, inferential statistics ($p$-values, effect sizes, Welch-t tests), and cryptographic SHA-256 state hashing.

## Provenance & Verification

- Complete parameter logs, hardware envelopes, and environment metadata
- Mathematical formulations of every formal hypothesis
- SciPy test results ($t$-stats, $p$-values, effect sizes, Mann-Whitney $U$)
- SHA-256 cryptographic hashes for cleanroom sandbox verification
- Relative links to corresponding executable discovery notebooks in `../../experiments/`
